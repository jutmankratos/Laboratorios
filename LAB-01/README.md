# LAB-01

Repositorio de la primera tarea del laboratorio.

## Estructura

- `sql/`: scripts SQL de clasificación, enmascaramiento, seudonimización, anonimización y retención.
- `evidencias/`: evidencias PDF de cada actividad.
- `informe.md`: resumen y conclusiones del laboratorio.

## Estado

Plantilla inicial. Completa los scripts y reemplaza los PDF marcados como pendientes por tus evidencias.
